## 原创图解和小场景

核心词均有对应的原创图解；抽象词结合姿态、物品、方向或阶段示意，不用通用星星冒充缺图。新主题包括开包查看、屋内外切换、物品位置、动物动作关键帧、补给追加、虚拟价格、穿衣、森林地标、不同的村庄路线，以及读便条—找钥匙—开门—点亮灯塔—返营地的受限交互。

小场景在“看图听词”下展开，每次切换学习页面会重置，可反复探索。场景点击不自动解题或完成课程；动作图解为静态关键帧/方向示意，不宣称是视频或动作识别。

方向课明确角色面朝屏幕上方：第26课的公园在右侧，第28课的公园在左侧，使用不同地图。冷热有温度/角色感受提示；衣物按题目卡片判断；食品偏好是虚构角色的偏好，不评判孩子自己的口味。所有桥梁、动物、商店和路线操作只发生在屏幕，不是现实动物饮食、施工、付款或户外活动指导。

在原课程稿基础上修正4处干扰项（去掉元提示或明显不合场景的选项），学习目标和正确含义不变，详情见 `course-source.json`。U01原题目、选项和音频ID保持兼容。
